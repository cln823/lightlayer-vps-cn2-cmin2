## CN2、CMIN2、CMI 到底差在哪

大陆优化 VPS 指的是服务器放在境外，回程路由买了运营商的精品专线。普通国际线路从国内出去经常绕道，晚高峰丢包率能到两位数，这也是同样配置的机器价格能差三四倍的原因。

几条常见线路的定位：

- **CN2 GIA（AS4809）**：电信顶级骨干，全程走 59.43 开头的节点，丢包率低，是电信用户公认的最优解
- **AS9929**：联通精品骨干，定位和 CN2 GIA 接近
- **CMIN2（AS58807）**：移动国际精品网，近两年质量提升明显，联通用户走也有不错表现
- **CMI（AS58453）**：移动国际线路，比 CMIN2 便宜一档，质量次之
- **163（AS4134）和 AS4837**：电信、联通的普通线路，晚高峰是重灾区

LightLayer 两条线的分工很清楚。圣何塞 Premium 标注的是 CN2 优化，面向国内访问，对电信线路更友好；洛杉矶优化系列的回程走 CMIN2，电信联通移动三网都能受益，联通和移动用户的实际体验往往比纯电信优化线路更均衡。

选哪条取决于你的用户构成。访问者以电信宽带为主，CN2 更对路；联通、移动占多数，CMIN2 不吃亏。这两条线都没有“三网全 CN2 GIA”的规格，不必为不存在的东西纠结。

**圣何塞和洛杉矶哪个延迟低？**

1 核 1G、50G 硬盘，跑一个日均几千 PV 的静态站或 WordPress、做轻量代理、开发测试都够。跑数据库、编译、同时开多个容器会吃紧，那就往 2 核 2G 走。

**能装 Windows 吗？**

LITE 款明确只支持 Linux，这一点写在产品说明里。L 款和洛杉矶系列没有列出 Windows 选项，有这个需求建议先开工单确认再下单。

**流量用完了会停机吗？**

公开资料只提到 LITE 款支持额外购买流量包，没写超量后的具体处理方式。用量大的话，下单前问清楚超量是限速还是停机。

**续费会涨价吗？**

没有找到明确的首年价与续费价差异说明。LightLayer 的年付折扣是按计费周期给的，看起来不像首年专属，但下单时值得在购物车里核对一下续费周期显示的价格。
